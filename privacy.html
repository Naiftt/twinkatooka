Privacy Policy

TwinkaTooka Studio · last updated 30 October 2026 · Home

Who we are

TwinkaTooka Studio is a private tool used by the owner of the TwinkaTooka YouTube channel (youtube.com/@twinkatooka) to manage that channel. It is not offered to the public, and it is used only with the owner's own Google account.

What data the tool uses

With the owner's permission (Google sign-in), the tool uses the YouTube Data API and the YouTube Analytics API to: upload the channel's own videos and thumbnails; edit their titles, descriptions, tags and playlists; add and read caption tracks (subtitles) of the channel's own videos; and read the channel's own statistics (views, watch time, retention, subscribers, traffic sources and countries, all as totals).

The tool does not collect, store or use any personal information about viewers, including children. It does not read comments, does not contact anyone, and contains no advertising or tracking.

How the data is kept and shared

The sign-in token and the statistics reports are kept only on the owner's own computer. Nothing is sold or shared with anyone. Data is used only to run and improve the TwinkaTooka channel.

TwinkaTooka Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The owner can remove the tool's access at any time at myaccount.google.com/permissions, and delete the token on their computer.
